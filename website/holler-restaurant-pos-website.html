How it works

Cloud when available. Local when it matters.

Your restaurant does not change its workflow because an ISP has a bad evening.

01

Install on your Windows machine

02

Run the whole day offline

Orders, bills, KOTs, staff login and KDS keep working locally.

03

Sync when you're back online

Queued operational data is pushed to the cloud automatically.

A practical difference

Designed around failure, not perfect WiFi.

Cloud connectivity is useful. It should not be a prerequisite for printing a bill during service.
